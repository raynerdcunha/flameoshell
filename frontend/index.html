01 CAPABILITIES

Everything you expect from a shell.

FlameOShell brings together the fundamental Unix process and shell concepts into one lightweight program.

⚡

Command execution

Parse commands and launch programs using the operating system's process model.

fork() + execve()
🔗

Pipes

Connect processes together and move output from one command directly into another.

pipe()
📂

Redirection

Redirect standard input and output using files, just like a traditional Unix shell.

open() + dup2()
🧵

Background jobs

Run processes in the background while keeping the shell available for more commands.

& + jobs
🎮

Job control

Move processes between foreground and background execution with shell-level job management.

fg + bg
🛡️

Signal handling

Handle process signals and terminal events while maintaining control of running jobs.

sigaction()
